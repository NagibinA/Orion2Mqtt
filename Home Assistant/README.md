**Платформа теперь: ESP32 (вместо ESP8266).**

## 📋 Обзор

Orion2Mqtt — это мостовое приложение, которое соединяет устройства **Orion (Болид)** через интерфейс **RS485** с **MQTT брокером**, используя плату **ESP32** и фреймворк **ESPHome**.

Проект полностью переписан на **ESPHome**, что позволяет:
- Управлять устройством через Home Assistant "из коробки"
- Обновлять прошивку по воздуху (OTA)
- Настраивать всё через единый YAML-файл без компиляции

## ✨ Возможности

- ✅ Преобразование RS485 → MQTT
- ✅ Автоматическое вычисление и проверка **CRC8**
- ✅ **LWT** (Last Will and Testament) для мониторинга статуса
- ✅ Автоматическое переподключение к WiFi и MQTT
- ✅ Ожидание ответа от устройства (таймаут 200 мс)
- ✅ Публикация ответов в MQTT одним пакетом

## 🧰 Аппаратные требования

| Компонент | Рекомендация |
|-----------|---------------|
| **Микроконтроллер** | ESP32 (любая плата: DevKit, Wemos Lolin32, NodeMCU-32) |
| **Преобразователь RS485** | MAX485 (или аналогичный) |
| **Устройства Болид** | С2000-БКИ, С2000-КДЛ, и любые другие с протоколом Orion |

## 🔌 Подключение

### Схема соединений (для ESP32)

| Пин ESP32 | Модуль MAX485 | Функция |
|-----------|---------------|---------|
| **GPIO2** | RE/DE         | Управление RTS (передача/приём) |
| **GPIO17**| DI            | Передача данных (TX) |
| **GPIO16**| RO            | Приём данных (RX) |
| **GND**   | GND           | Общий провод |
| **5V**    | VCC           | Питание (5V) |

> ⚠️ **Внимание:** Убедитесь, что ваш ESP32 может питать MAX485 (иногда требуется внешнее питание). Скорость шины — **9600 бод**.

### Альтернативные пины

Если нужны другие пины — измените значения `tx_pin`, `rx_pin` и `pin` для `rs485_rts` в YAML-конфигурации.
